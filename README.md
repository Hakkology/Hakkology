# Hi 👋 I'm Hakan

I am a **Software & Game Developer** experienced in C#, C++, and .NET, specializing in Python and Rust, focused on building critically useful engineering tools, enterprise systems, and desktop applications. I am the founder of **Morcalavin Games**, an indie studio dedicated to PC and mobile title development.

I bring 3+ years of professional experience in the .NET ecosystem, including 1 year spent working as a Game Developer at **IBrightGames**. Lately, I have been deeply focusing on the **Rust** ecosystem, exploring low-level computing, custom engines, visual tools, and graphics architecture. I also bring foundational experience as a former Unity Instructor, having taught gameplay architecture and software production workflows.

### 🚀 Technical Overview
- **Rust & Low-Level Systems:** Actively building core utilities, engines, and tools in Rust. Projects include high-performance 2D CAD engines (**MuginCAD**), custom **ECS** implementations, a radio broadcaster (**Crabcast**), and custom **OpenGL renderers** built from scratch. Experienced with **Bevy**, raytracing concepts, and GPU computing using **CUDA** and **WebGPU**.
- **Game Development:** Experienced in **Unity** architecture and actively developing PC games in **Godot**. Passionate about complex simulation mechanics, **RTS frameworks**, pathfinding algorithms, and procedural generation methods.
- **Mobile Development:** Focused on mobile deployment pipelines, configuring Firebase environments, and implementing native mobile functionality, including handling Android/Java source layers (`.aar`) for plugin integrations.
- **Web & Enterprise Architecture:** Strong background in full-stack ERP architectures, traditional MVC frameworks, and high-end **nopCommerce** e-commerce ecosystems. Specialized in performant interfaces and enterprise dashboards using **Blazor (MudBlazor / DevExpress)**, **WPF (MVVM)**, and **Avalonia**.
- **Infrastructure & DevOps:** Deep expertise in environment deployment and server maintenance. Proficient in managing a private environment orchestrated with **Docker**, currently managing 4 live production environments on **Linux (Debian/Ubuntu)** systems. Experienced in writing custom automated shell scripts, setting up IIS environments, and configuring desktop lifecycle update pipelines via **Velopack** and **ClickOnce**.
